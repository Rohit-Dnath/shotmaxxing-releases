# ShotMaxxing

Desktop video editor for Reels, YouTube Shorts and TikTok. This repository only hosts the installers and update files.

## Download

- **Windows:** [ShotMaxxing-Setup.exe](https://github.com/Rohit-Dnath/shotmaxxing-releases/releases/latest/download/ShotMaxxing-Setup.exe)
- **Mac (Apple Silicon):** [ShotMaxxing-mac-arm64.dmg](https://github.com/Rohit-Dnath/shotmaxxing-releases/releases/latest/download/ShotMaxxing-mac-arm64.dmg)

You need a license key to use the app. Get one at https://shotmaxxing.vercel.app/account
